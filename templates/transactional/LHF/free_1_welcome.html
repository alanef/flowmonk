How It Works

  1. Upload your HTML files to /wp-content/uploads/html_file/unprocessed/
  2. The plugin checks for new files every 5 minutes
  3. Each file becomes a post in the "HTML Files" custom post type
  4. The first <h1> becomes the post title
  5. Processed files move to the processed folder

Folder Structure

Organise files into subfolders to create automatic category hierarchies:

unprocessed/category/subcategory/file.html

What Gets Cleaned

The plugin removes <html>, <body>, and <script> tags automatically – just keeping the content that goes inside WordPress.

Originally built for Sailwave results, but it works with any HTML files.
