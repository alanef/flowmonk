Just a quick note about what Stop User Enumeration is doing for your site.

Why This Matters

Most brute-force attacks follow a pattern:

  1. Reconnaissance – probe the site to find valid usernames
  2. Attack – hammer the login page with password guesses

Stop User Enumeration breaks step 1. Tools like WPScan can no longer discover your usernames automatically. Attackers are forced to guess both the username and the password – massively reducing their odds.

If You Run a VPS or Dedicated Server

The plugin logs blocked attempts via syslog. If you use fail2ban, you can automatically block repeat offenders at the firewall level. There's a filter example in the plugin documentation.

Advanced Options

The plugin has some optional settings you might want to check:

  • REST API blocking – on by default, blocks /users endpoint
  • Author sitemap removal – prevents WordPress exposing users in sitemaps
  • oEmbed filtering – removes author data from embedded content

Find these in Settings → Stop User Enumeration.
