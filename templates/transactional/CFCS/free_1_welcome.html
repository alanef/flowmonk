Getting Started

Add the form to any page or post with this shortcode:

[cscf-contact-form]

That's it. Messages go to your WordPress admin email address (the one in Settings → General).

Customisation

Find the settings at Plugins → Installed Plugins → Settings (next to the plugin name). You can:

  • Change the success message
  • Add multiple recipient email addresses
  • Enable email confirmation field
  • Add a phone number field
  • Enable GDPR consent checkbox
  • Set up reCAPTCHA if you want it

Bootstrap Compatible

The form uses Twitter Bootstrap CSS classes, so it should fit nicely with most themes. If you want to use your theme's styling instead, you can disable the plugin's stylesheet in settings.
