A Few Tips

Not receiving emails?

Check your spam folder first. If emails aren't arriving at all, your hosting might be blocking them. Try an SMTP plugin like WP Mail SMTP to send via a proper mail service.

Want instant feedback?

The form uses AJAX by default – visitors see validation messages without the page reloading. You can turn this off in settings if it conflicts with your theme.

Multiple recipients?

In settings, you can add multiple email addresses separated by commas. All recipients get the same message.

For Developers

The plugin has a REST API if you need to integrate the form with external apps or headless WordPress setups. Enable it in settings and check the documentation for endpoint details.
