What It Does

The plugin scans your site for known vulnerabilities in:

  • WordPress core
  • Installed plugins
  • Installed themes

It checks against the WordPress Vulnerability Database and alerts you via email when issues are found.

Getting Started

  1. Go to Settings → Fullworks Vulnerability Scanner
  2. Set your email address for alerts
  3. Configure scan frequency (daily by default)
  4. Review the initial scan results

WP-CLI Support

Run manual scans from the command line:

wp fullworks-scanner
