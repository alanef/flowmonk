I'm Alan, the developer of Stop WP Emails Going to Spam. Thanks for installing it.

The plugin is now fixing a common issue with WordPress on shared hosting: missing envelope sender headers. Without these, many email providers mark WordPress notifications as spam.

What It Does

  • Sets the "envelope sender" when your server doesn't
  • Lets you change the default "WordPress" sender name
  • Lets you set a proper sending email address

Test It

Go to your WordPress site and trigger an email – maybe a password reset or a test contact form submission. Then check your inbox (and spam folder).

If emails are still going to spam, the plugin has a diagnostics section that checks your SPF records and whether your server IP is blacklisted. Have a look in the settings.

Important Note

This plugin is for sites using PHP's default mail function. If you're already using an SMTP plugin or a transactional email service like SendGrid or Mailgun, this plugin won't add anything – those services handle headers properly already.
