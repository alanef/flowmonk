Getting Started

Basic usage:

[pw_map address="Your Address Here" key="YOUR_API_KEY"]

You'll need a Google Maps API key. It's free for most usage. Get one here.

Shortcode Options

  • address – the location to pin
  • key – your Google Maps JavaScript API key
  • geokey – your Google Geocoding API key (optional, for better security)
  • width – map width (default: 100%)
  • height – map height (default: 400px)
  • zoom – zoom level (default: 15)
  • maptypeid – roadmap, satellite, hybrid, or terrain

Multiple Pins

Show multiple locations by separating addresses with semicolons:

[pw_map address="Location 1; Location 2; Location 3" key="YOUR_KEY"]
